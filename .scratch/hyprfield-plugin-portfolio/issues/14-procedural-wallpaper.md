# 14 — Procedural Wallpaper

**What to build:** Let users configure and run an independently useful monitor-scoped procedural wallpaper whose deterministic chunked WFC generation, presentation, caching, and fallback remain bounded and strictly behind authoritative surfaces.

**Blocked by:** 11 — Plugin Collection Foundation and Host Harness

**Status:** ready-for-agent

- [ ] Native Lua accepts a bounded declarative ruleset and produces deterministic coordinate-addressed chunks with compatible seams.
- [ ] Viewport-driven generation enforces bounds for observations, retries, queues, resident chunks, prefetch, and texture memory.
- [ ] Delayed or failed generation uses deterministic fallback content and does not block interaction.
- [ ] Seed, ruleset, and generator versions isolate cache namespaces; restart metadata preserves visited-region identity without persisting GPU textures.
- [ ] Presentation stays behind applications, fullscreen surfaces, lock screens, and other authoritative surfaces, with covered animation paused or degraded.
